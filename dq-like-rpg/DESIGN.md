# ひよこ勇者よよよーの大冒険 設計書

ドラゴンクエスト3のシステム(職業選択パーティ制、ターン制コマンドバトル、フィールド探索、町・ダンジョン構成、レベル成長)を参考にしつつ、シェアハウス運営の日々のドラマを魔物・ダンジョン・ボスとして寓話化したブラウザRPGの設計書。

**サブタイトル:** ～シェアハウスの終わらぬ黄昏を払うもの～

---

## 1. 世界観・シナリオ概要

### 1.1 世界設定

大陸「アルテヴィア」は、4つの星霜晶設備核によって水道、防災、共有庭、照明と契約の仕組みを保っていた。管理契約の処理が終わらなくなり、生活の困りごとが積み重なった結果、朝が来ない「終わらぬ黄昏」が発生している。

主人公は星霜荘の副管理人「ひよこ勇者よよよー」。住人の苦情、設備修理、掲示物、家賃、退去対応を解決しながら、終わらない管理処理の原因を探す。

### 1.2 主人公・旅立ち構成

- **タイトル画面**でプレイヤーが入力する名前は `RPG.state.heroName` に保存される。
- **旅立ち時**のパーティは **「よよよー」(職業 `yoyoyo`) 1人のみ**（`engine.js` の `startNewGame`）。
- 入力名は副管理人の記録名として保存され、バレンシュタットで契約監査人(`akatsukiKenshi`)が加入する。
- ミレスタ村は前任管理人の研修所として残し、既存のマップ・戦闘構成を活かして星霜荘へ向かう。

### 1.3 メインシナリオ(章立て)

1. **序章:副管理人の初仕事** - ミレスタ研修所でゴミ出し、掲示物、清掃用品の対応。
2. **第一章:涸れ井戸の設備点検** - 給水設備の停止原因を調べ、設備修繕員と合流。
3. **第二章:家賃と自動送金の都** - バレンシュタットで二重徴収と契約トラブルを解決。
4. **第三章:災害対応と封牙洞** - 避難経路と防災設備を復旧し、生活相談員と合流。
5. **第四章:壁の耳と紙の雨の集落** - 星霜荘を本編の拠点とし、日々の管理案件を解決。
6. **第五章:自動管理システムの暴走** - 管理人AIを停止し、住人と新しいルールを作る。
7. **終章:終わらぬ契約の管理王** - 管理契約の核ゾルガディアを停止し、朝を取り戻す。

### クリア目標・エンディング

- **メインルート**: ゾルガディア撃破 → `flags.gameCleared` → `screen-ending`（シェアハウスと大陸に朝が戻るエンディング）。
- **シェアハウス中盤**: `shareHouseOverseer` 撃破 → 管理AI停止 → 住人と新しいルールを作る。よよよーは変身・離脱しない。
- **裏管理室ルート**: 通常エンディング後に`postgameUnlocked` → 裏管理室の導入 → `chickEmperor`（管理権限暴走形態）撃破 → 裏エンディング。
- 最初のボス撃破で `flags.classChangeUnlocked` が立ち、教会(Lv20以上)で転職可能。
- **風来の勇者(`fuuraiNoYuusha`)**: 旅がらすが **全滅3回**(`flags.defeatCount >= 3`)で `flags.metCriteriaForFuurai` が立ち、転職候補に出現。

### 1.4 旧設計メモ(参考)

旧案では星霜晶と魔王が中心だった。現行コードではシェアハウスの日常と管理契約を中心に扱う。

## 2. 職業システム(オリジナル職)

DQ3の「戦士/魔法使い/僧侶/武闘家/商人/遊び人/勇者」を生活管理の役割へ置き換えた職業群。パーティは**副管理人よよよー + 職業選択可能な仲間3人**の計4人編成。

| オリジナル職名 | 元ネタ相当 | 特徴 |
|---|---|---|
| **副管理人よよよー** | 勇者 | 主人公固定。小回りと幸運で現場の問題を解決する。 |
| **設備修繕員** | 戦士 | HP・力が高い。壊れた設備を直す物理アタッカー。 |
| **掲示物解析士** | 魔法使い | MPが高く、契約文や暗証番号を解析する攻撃呪文が豊富。 |
| **生活相談員** | 僧侶 | 住人の回復・健康相談・避難運営を担う。 |
| **夜間巡回員** | 武闘家 | 素手武器不要で高い会心率。騒音対応が得意。 |
| **備品調達員** | 商人 | どうぐの所持数上限と戦闘後の収入が増加。 |
| **短期入居者** | 遊び人 | 序盤は戦力にならないが、条件達成で風来の管理人へ転職できる。 |

- パーティ編成は町の教会・星霜酒場で仲間を選び、以後「転職の祠」で自由に転職・再編成可能。
- 転職してもレベルはリセットされず、ステータスは職業ごとの補正値で再計算する(DQ3方式の簡易版)。

## 3. ステータス・レベル・経験値

### 3.1 基本ステータス

- **HP**(最大HP) / **MP**(最大MP)
- **ちから**(物理攻撃力に影響)
- **まもり**(被ダメージ軽減)
- **すばやさ**(行動順・回避に影響)
- **かしこさ**(呪文ダメージ・MP量に影響)
- **うんのよさ**(会心率・状態異常耐性に影響)

### 3.2 レベル・経験値テーブル

`data.js` の `EXP_TABLE配列`(Lv1〜Lv30、計30段階)により必要累計経験値を定義。レベルアップ時、職業ごとの成長率(`data.js` の `JOB_GROWTH`)に基づき各ステータスが加算される。

```
必要経験値(Lv) = EXP_TABLE[Lv - 1]
例: Lv1→2: 7, Lv2→3: 23, ... Lv29→30: 12800 (逓増カーブ)
```

### 3.3 経験値・ゴールド獲得

戦闘勝利時、敵グループの `exp` と `gold` 合計をパーティ全員(生存者)に分配。レベルアップ時は習得呪文チェックを行い、新規呪文があればメッセージ表示。

## 4. オリジナル呪文体系

呪文系統を4系統に分類。呪文名はすべてオリジナル。

| 系統 | 呪文名 | 効果 | 習得職 |
|---|---|---|---|
| 攻撃(炎) | イグナル / イグナドス / イグナジオン | 敵単体/敵全体に炎ダメージ(小/中/大) | 星読み、暁の剣士 |
| 攻撃(氷) | クリスタ / クリスタドス | 敵単体/敵全体に氷ダメージ | 星読み |
| 攻撃(雷) | ヴォルテカ | 敵全体に雷ダメージ | 星読み |
| 回復 | ヒールミア / ヒールミアラ / ヒールミアガ | 味方単体HP回復(小/中/大) | 癒しの巫女、暁の剣士 |
| 全体回復 | メギルーナ | 味方全体HP回復 | 癒しの巫女 |
| 蘇生 | リザレクア | 戦闘不能から復活 | 癒しの巫女 |
| 補助(強化) | ブレスヴァル | 味方単体の攻撃力上昇 | 癒しの巫女、暁の剣士 |
| 補助(防御) | シェルガード | 味方単体の守備力上昇 | 癒しの巫女 |
| 状態異常 | スリプティア | 敵単体を眠り状態に | 星読み |
| 状態異常 | パラライズン | 敵単体を麻痺状態に | 星読み |
| 移動系 | ワープリンド | フィールドで町へ帰還(帰還呪文) | 暁の剣士、星読み |
| 専用(勇者) | 黎明衝(れいめいしょう) | 敵単体に大ダメージ+味方全体HP微回復 | 暁の剣士(Lv20習得) |

呪文データは `data.js` の `SPELLS` オブジェクトに `{id, name, mpCost, target, power, element, effectType}` の形式で定義する。

## 5. バトルシステム(ターン制コマンドバトル)

### 5.1 コマンド

DQ3同様、味方全員のコマンドを先に入力してから一括処理する方式。

- **たたかう** - 敵単体に物理攻撃
- **じゅもん** - 呪文選択サブメニューを開き、対象を選ぶ
- **どうぐ** - 所持アイテムから使用アイテムを選ぶ
- **ぼうぎょ** - 被ダメージ軽減、次ターンまで防御姿勢
- **にげる** - パーティ全体の逃走判定(すばやさ平均で成功率決定)

### 5.2 行動順

すばやさ順(乱数補正込み)で全キャラ・全モンスターの行動をソートし、順番に処理。

### 5.3 ダメージ計算(簡易式)

```
物理ダメージ = max(1, 攻撃側ちから * 補正 - 防御側まもり / 2) ± 乱数(±10%)
呪文ダメージ = max(1, 呪文power + 攻撃側かしこさ/2 - 敵の呪文耐性) ± 乱数(±10%)
会心率 = 基礎1/32 + うんのよさ補正
```

### 5.4 戦闘フロー(状態遷移)

`ENCOUNTER開始 → コマンド入力(勇者→仲間1→仲間2→仲間3の順にUI表示) → 行動順計算 → 行動実行(ログ表示) → 勝敗判定 → (勝利:経験値/ゴールド/アイテム獲得 | 敗北:町へ強制帰還 | 継続:次ターンへ)`

### 6.2 ランダムエンカウント

草原・森・灰霧地帯タイルを1歩進むごとに乱数判定(基礎確率は `map.js` の `ENCOUNTER_RATE` で管理、タイルごとに倍率補正)。判定成功で現在地の「エリアID」に紐づくモンスター出現テーブル(`data.js` の `ENCOUNT_TABLES`)から敵グループを抽選し、`battle.js` の戦闘へ遷移。

### 6.3 移動・描画

- 8x8〜16x16程度のタイルグリッドをCanvasにグリッド単位で描画。
- 主人公は矩形+簡易顔アイコン(SVGまたはCanvas図形)で表現、方向キー/矢印キーで4方向移動。
- カメラは常に主人公中心にスクロール(マップがビューポートより大きい場合)。

## 7. 町の構成

各町共通で以下4施設(建物アイコンをクリック/タップでメニュー展開)。

- **宿屋(やすらぎの宿)** - 一定ゴールドでHP/MP全回復、セーブ確認ダイアログを兼ねる。
- **武器屋(かじやのつぐみ)** - 武器・防具の購入/売却。職業ごとの装備可否あり。
- **道具屋(旅路の雑貨店)** - 消耗品(やくそう相当のオリジナルアイテム等)の購入/売却。
- **教会(星霜の礼拝堂)** - 状態異常回復、蘇生(有償)、パーティ仲間の加入・並び替え、(中盤以降)転職。

町ごとに固有NPCとの会話でシナリオフラグを進行させる。町マップもタイルベースで、施設タイルへの侵入でメニューが開く。

### 主要な町(例)

1. ミレスタ村(序章)
2. ファルンハイム(交易前哨・武具強化)
3. バレンシュタット(商人ギルドの都、大規模市場)
4. 静霧の里リエンナ(第三章・僧侶仲間加入)
5. 最終前線基地アルテヴィア城塞(終章直前の拠点)

## 8. ダンジョン(2つ以上)

1. **涸れ井戸の遺跡(かれいどのいせき)** - 序盤ダンジョン。地下3階層。ボス「石守り人ゴレムナス」。蒼の星霜晶欠片を入手。
2. **封牙洞(ふうがどう)** - 中盤ダンジョン。灰霧の森の奥。地下4階層+隠し部屋。ボス「牙獣王フェルバイト」。紅の星霜晶欠片を入手。
3. **(追加)蒼波の水没神殿** - サブダンジョン、船入手後の探索用。装備強化素材を入手可能(任意攻略)。
4. **天蓋の破れ目(てんがいのやぶれめ)** - 最終ダンジョン。5階層構成、各階に中ボス配置。最深部でラスボス「終わらぬ契約の管理王ゾルガディア」と対峙。

ダンジョンもフィールドと同じタイルエンジンを使い回すが、`TILE_TYPES` に「壁」「宝箱」「階段(上/下)」を追加したセットを使用する。宝箱はオリジナル装備・アイテムを配置。

## 10. セーブ/ロード(localStorage)

### 10.1 保存キー

`localStorage` キー: `"seisou_frontier_save_v2"`

### 10.2 保存データ構造(JSON)

```js
{
  version: 2,
  playTime: 12345,          // 秒
  party: [
    { name, job, level, exp, hp, maxHp, mp, maxMp, stats: {...}, equipment: {...}, spells: [...] },
    ...
  ],
  gold: 1234,
  inventory: [ { itemId, count }, ... ],
  flags: { chapter: 3, defeatedBosses: [...], ... },
  position: { mapId: "farnheim", x: 5, y: 8 },
  starFragments: ["blue", "red"]
}
```

### 10.3 API

- `RPG.save.save()` - 現在の `RPG.state` をシリアライズして `localStorage` に書き込み
- `RPG.save.load()` - `localStorage` から読み込み、`RPG.state` に復元(存在しない場合は `null` を返す)
- `RPG.save.hasSave()` - セーブデータ存在確認
- `RPG.save.clear()` - セーブデータ削除(タイトル画面の「はじめから」用)

宿屋・特定セーブポイントで `RPG.save.save()` を呼ぶ。タイトル画面で `hasSave()` により「つづきから」ボタンの活性/非活性を切り替える。

## 12. モジュール間インターフェース(`window.RPG` 名前空間)

すべてのモジュールはグローバル汚染を避けるため `window.RPG` 配下にサブ名前空間として登録する。

```js
window.RPG = {
  data: { ... },     // data.js が提供。JOBS, SPELLS, ITEMS, MONSTERS, MAPS, ENCOUNT_TABLES, EXP_TABLE, JOB_GROWTH, TILE_TYPES
  state: { ... },    // engine.js が管理する可変な現在の状態(party, gold, inventory, flags, position, scene)
  engine: { ... },   // engine.js が提供するAPI
  map: { ... },      // map.js が提供するAPI
  battle: { ... },   // battle.js が提供するAPI
  ui: { ... },       // ui.js が提供するAPI
  save: { ... },     // engine.js内に実装するセーブ/ロードAPI
};
```

### 12.1 `RPG.data`(data.js が定義、読み取り専用として扱う)

- `JOBS`: 職業定義 `{ jobId: { name, baseStats, growth, learnableSpells, equipableTypes } }`
- `SPELLS`: 呪文定義 `{ spellId: { name, mpCost, target, power, element, effectType } }`
- `ITEMS`: アイテム/装備定義 `{ itemId: { name, type, price, effect, statBonus } }`
- `MONSTERS`: モンスター定義 `{ monsterId: { name, stats, exp, gold, dropTable, spriteShape } }`
- `ENCOUNT_TABLES`: エリアID→出現モンスターグループ抽選テーブル
- `EXP_TABLE`: レベル別必要累計経験値配列
- `JOB_GROWTH`: 職業別レベルアップ成長率
- `TILE_TYPES`: タイルID→ `{ color, walkable, encounterRate, type }`
- `MAPS`: マップID→ `{ width, height, tiles(2次元配列), areaId, warps, npcs }`

### 12.2 `RPG.engine`(engine.js)

- `RPG.engine.init()` - ゲーム全体の初期化(データロード、キャンバス取得、タイトル画面表示)
- `RPG.engine.startNewGame(heroName)` - 初期パーティ生成、初期位置セット、序章シーンへ
- `RPG.engine.changeScene(sceneName, params)` - シーン遷移(`"title" | "field" | "town" | "dungeon" | "battle" | "menu"`)を一元管理。現在シーンのループを止め、新シーンの `enter()` を呼ぶ
- `RPG.engine.gainExp(partyMember, exp)` - 経験値付与とレベルアップ処理・新規呪文判定
- `RPG.engine.gainGold(amount)` / `RPG.engine.spendGold(amount)`
- `RPG.engine.getParty()` / `RPG.engine.getFlags()` などの状態アクセサ
- `RPG.engine.tick(timestamp)` - `requestAnimationFrame` ベースのメインループ、現在シーンの `update`/`render` を呼ぶ
- `RPG.save.save()` / `RPG.save.load()` / `RPG.save.hasSave()` / `RPG.save.clear()`

### 12.3 `RPG.map`(map.js)

- `RPG.map.enterField(mapId, startX, startY)` - フィールド/町/ダンジョン共通のマップ進入処理
- `RPG.map.update(dt)` - 入力処理、移動、タイル判定、エンカウント判定
- `RPG.map.render(ctx)` - タイルとキャラをCanvasに描画
- `RPG.map.checkEncounter(tile)` - 内部利用。エンカウント成立時 `RPG.engine.changeScene("battle", {monsterGroup})` を呼ぶ
- `RPG.map.onTileAction(tile)` - 町施設タイル・階段・宝箱などのインタラクション処理

### 12.4 `RPG.battle`(battle.js)

- `RPG.battle.enter(monsterGroup)` - 戦闘開始、UI初期化
- `RPG.battle.queueCommand(actorId, command, target)` - `ui.js` から呼ばれ、コマンドをターンキューに積む
- `RPG.battle.resolveTurn()` - 行動順計算・ダメージ計算・状態更新・ログ生成
- `RPG.battle.checkBattleEnd()` - 勝敗判定、勝利時 `RPG.engine.gainExp`/`gainGold` 呼び出し、敗北時タイトルまたは町へ
- `RPG.battle.calcDamage()` - ダメージ計算
- `RPG.battle.showFloatingText(cx, cy, value, style)` - 戦闘Canvas上のダメージ/回復数字(C-6)。弱点=橙、耐性=灰、会心=金、回復=緑。
- `RPG.ui.showFloatingText()` - 上記のUI層フック(描画本体は battle.js)

### 12.5 `RPG.ui`(ui.js)

- `RPG.ui.showMessage(text, callback)` - メッセージウィンドウ表示(1文字送り演出)。`battle.js`の`pushLog`からのみ駆動され、戦闘シーンの`update`から毎フレーム呼び出すことはしない(呼ぶと配列を文字列として処理しようとして必ず壊れるため)。
- `RPG.ui.openMenu(menuType, options)` - `"command" | "spell" | "item" | "shop" | "status"` 等の各種メニューをDOM/Canvasで開く。矢印キー(上下)でselectedIndexを移動、Zキーで決定、Xキーで`options.onCancel`(未指定時はcloseMenu)を実行する。
- `RPG.ui.closeMenu()`
- `RPG.ui.renderBattleUI(battleState)` - 戦闘中のHP/MPバー・コマンドウィンドウ描画。`battle.js`の`enter()`とターン解決後にのみ呼び出す。
- `RPG.ui.openShop(shopId, mode)` - 武器屋/道具屋の売買UI(`mode: "buy" | "sell"`)
- `RPG.ui.openChurch(churchId)` - 教会メニュー(蘇生/状態回復/転職/仲間並び替え)。並び替え・転職は共通のヘルパー(`openReorderMenu`/`openJobChangeMenu`)を実際に呼び出し、メニュー画面への丸投げはしない。
- ステータス画面から装備スロット(武器/防具/装飾品)を選び、所持アイテムから装備・解除できる(`openEquipMenu`)。装備した`statBonus`は`battle.js`の`statOf()`経由でダメージ計算に反映される。
