## 2. 旧ロードマップ(参考: パッケージA〜C詳細)

※以下は実装済み。履歴として残す。

**担当ファイル: data.js(主)、map.js(落とし穴・隠し通路・祈り床の判定)、gfx.js(祈り床・橋の描画があれば)**

### A-1. ダンジョン全面リメイク方針

`makeRuinsFloor` 等の「全面床関数」を廃止し、各階を手書きレイアウト(setRect/setTileの組合せ、または文字列マップ→配列変換ヘルパー)で個別設計する。共通ルール:

- **1階あたりの想定歩数: 80〜150歩**(入口→階段最短で40歩前後、宝箱全回収で+60歩)。「適度な長さ」= 1ダンジョン10〜15分
- 各階に **分岐2〜3箇所、行き止まり1〜2箇所(うち1つは宝箱で報酬化)**
- **ループ回廊**を各ダンジョン最低1フロアに(ぐるっと回って入口付近に戻る)
- ボス階は「試練の一本道(短)+分岐宝物庫(宝箱2〜3)」の2ブロック構成

### A-2. 各ダンジョンの具体設計

| ダンジョン | サイズ変更 | 地形コンセプト |
|---|---|---|
| 涸れ井戸の遺跡 B1〜B3 | 10×10 → **14×14** | B1: 十字通路+四隅小部屋 / B2: 渦巻き回廊(外周→中心) / B3: 一本道→ボス+分岐宝物庫(鋼の剣を配置し買わずに取れる選択肢を用意しない=防具側を置く) |
| 封牙洞 B1〜B4 | 12×12 → **16×16** | B1: ループ回廊 / B2: 隠し通路(壁に見える通行可タイル)の先に隠し部屋 / B3: **落とし穴フロア**(正解ルート以外は踏むとB4の入口付近に落下=罠だが実は近道) / B4: 一本道+宝物庫+ボス |
| 蒼波の水没神殿 | 10×10 → **12×12** | 「見えるのに行けない宝箱」: 水路(タイル3)の対岸に宝箱を見せ、大回りの桟橋ルートで到達 |
| 天蓋の破れ目 F1〜F5 | 12×12 → **16×16** | F1: 迷路 / F2: 中ボス(隊長)+宝物庫 / F3: 落とし穴+隠し通路の複合 / F4: 中ボス(監視者)+宝物庫 / F5: 祈り床→長い一本道→ラスボス |

### A-3. 追加タイル(TILE_TYPES)

| ID | 名称 | walkable | 挙動 |
|---|---|---|---|
| 21 | 落とし穴 | true | 踏むと `mapDef.pitfalls` の定義先へ強制ワープ(map.js `onTileAction` にケース追加) |
| 22 | 隠し通路 | true | 見た目は壁色(#333333)より僅かに明るい #3a3a3a。描画は壁と同形(gfx.js)、通行可 |
| 23 | 祈り床 | true | 踏むとHP/MP全回復+セーブ確認(map.js にフック)。各ダンジョンのボス階に1枚 |

宝箱の中身は `mapDef.chests: [{x, y, floor, itemId}]` 形式で明示定義に統一(現状の匿名宝箱を廃止)。配置例: 封牙洞隠し部屋=白狼の爪、天蓋F3隠し通路先=星霜のお守り。
